DR. HANDYMAN GITHUB SITE

Upload all files/folders in this package to the root of your GitHub repository.

To add a new photo later:
1. Open the images folder in GitHub.
2. Add file -> Upload files.
3. Upload JPG, JPEG, PNG, WEBP, GIF, or AVIF.
4. Commit changes.
5. GitHub Actions updates gallery-data.js automatically.
6. GitHub Pages redeploys; the new image appears in Gallery and the Home carousel.

Do not delete .github/workflows/update-gallery.yml.
